How to Install Factory Monitor
Audience: Project Engineers
Purpose: Guide users to install and set up the software to Factory Monitor
________________________________________
Introduction
Factory Monitor is a software package designed for monitoring plant and factory conditions. This guide provides step-by-step instructions for installing and configuring the software.
________________________________________
System Requirements
Ensure your system meets the following requirements before installation:
Supported Operating Systems
•	Windows 7 Professional
•	Windows XP/2003 or later
•	Windows Server 2008 (32-bit or 64-bit)
•	Windows 10
Hardware Specifications
•	Hard Drive Space: Minimum 100 MB
•	RAM: 100 GB or greater
•	Processor: Intel 3.0 GHz or faster
Additional Requirements
•	Microsoft Word and Excel installed (used for generating reports and parts lists).
________________________________________
Installation Steps
Follow these steps to install and configure Factory Monitor:
Step 1: Install the Software
1.	Insert the Factory Monitor installation CD into your computer.
2.	Run the setup file from the CD.
3.	Follow the on-screen instructions to complete the installation process.
Step 2: Configure System Settings
1.	Launch the Factory Monitor software.
2.	Set up user rights:
o	Assign access rights to users for different parts of the system.
o	Use the default System Administrator account for initial configuration.
Note:
o	Passwords must be at least 8 characters long.
o	Include special characters in passwords for security.
Step 3: Define Monitoring Parameters
1.	Specify the conditions or situations to monitor, such as:
o	Tank Overflow: Trigger an alarm if a tank is overfilled.
o	Valve Failure: Trigger an alarm if a valve does not open properly.
2.	Configure alarms with custom messages:
o	Provide clear instructions for remediation (e.g., "Check Tank Level Sensor").
Step 4: Test the System
1.	Verify that alarms are triggered correctly under defined conditions.
2.	Confirm that users receive the intended alarm messages.
________________________________________
Tips for Effective Use
•	Regularly update the system settings to reflect changes in plant operations.
•	Periodically review user permissions and reset passwords as needed.
•	Train plant floor staff to respond effectively to alarm messages.
